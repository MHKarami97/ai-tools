# AI Tools

مجموعه‌ای از ابزارهای هوش مصنوعی که **کاملا داخل مرورگر** اجرا می‌شوند؛ بدون سرور و بدون آپلود فایل. مدل‌ها یک‌بار دانلود و در مرورگر کش می‌شوند و بعد از آن برنامه به‌صورت PWA آفلاین هم کار می‌کند.

## ابزارها

### تبدیل متن به گفتار فارسی (TTS)
- پورت مرورگری موتور ONNX مدل Pocket-TTS برای زبان فارسی.
- مراحل: نرمال‌سازی متن فارسی، تبدیل به فونم (G2P)، توکنایز با SentencePiece، تولید latent با flow-LM، و دیکد صدا با Mimi decoder.
- کلون صدا از روی یک نمونه مرجع (حداکثر ۵ ثانیه) با Mimi encoder.
- تولید جمله‌به‌جمله با نوار پیشرفت، تنظیم سرعت (pace) و دو حالت برنامه‌ریزی متن (`normal` و `pack`).
- امکان سنتز مستقیم از فونم لاتین.
- کل استنتاج در یک Web Worker انجام می‌شود تا رابط کاربری قفل نشود.

### جداکننده صدا (Voice Splitter)
- جداسازی صدای خواننده از موسیقی با مدل htdemucs و کتابخانه `demucs-web` (روی `onnxruntime-web`).
- اجرای مدل با WebGPU و در صورت نبودن، WASM.
- ورودی MP3، WAV، M4A، OGG (و FLAC)؛ ورودی به ۴۴٫۱ کیلوهرتز تبدیل می‌شود.
- دو خروجی WAV: صدای خواننده و موسیقی بی‌کلام (مجموع drums، bass و other).
- دانلود مدل (حدود ۱۷۲ مگابایت) فقط بار اول انجام می‌شود و در IndexedDB کش می‌ماند.
- امکان لغو پردازش در حین اجرا.

## حریم خصوصی
- فایل‌های صوتی و متن‌ها هیچ‌جا ارسال نمی‌شوند و همه‌چیز روی دستگاه کاربر پردازش می‌شود.
- تنها ترافیک شبکه، دانلود اولیه فایل‌های مدل (از Hugging Face) است.

## فناوری‌ها
- Vue 3 + TypeScript + Vite
- PWA با Service Worker و پشتیبانی آفلاین
- `onnxruntime-web` (WebGPU / WASM)
- `demucs-web` برای جداسازی صدا
- Web Worker و IndexedDB برای پردازش و کش مدل

## ساختار پروژه

```text
src/
  components/   کامپوننت‌های مشترک و پنل‌های ابزارها
  composables/  توابع ترکیبی Vue
  config/       تنظیمات برنامه
  lib/
    tts/        موتور TTS (engine، G2P، نرمال‌سازی، DSP، دانلود مدل)
    splitter/   کلاینت، تایپ‌ها و کش مدل جداکننده
    ort/        راه‌اندازی onnxruntime-web
    npz.ts      خواندن فایل‌های NPZ
  pages/        صفحه‌ها (خانه، TTS، جداکننده، تنظیمات، آفلاین)
  router/       مسیریابی
  stores/       state برنامه
  workers/      ورکرهای TTS و Splitter
```

## راه‌اندازی

پیش‌نیاز: Node.js نسخه LTS.

```bash
npm install
npm run dev
```

برای ساخت نسخه نهایی:

```bash
npm run build
```

نام دقیق اسکریپت‌ها را در `package.json` ببینید.

## مدل‌ها

| ابزار | مدل‌ها | منبع | ذخیره‌سازی |
|---|---|---|---|
| TTS | flow، encoder، decoder، وزن‌ها، sentencepiece، g2p (ONNX/NPZ) | Hugging Face (مسیر در `src/lib/tts/modelRegistry.ts`) | IndexedDB |
| Splitter | htdemucs (ONNX) | آدرس پیش‌فرض `demucs-web` | IndexedDB |

- برای نمایش نوار پیشرفت و زمان تقریبی دانلود، حجم فایل‌های TTS در `modelRegistry.ts` تخمینی است و باید با حجم واقعی فایل‌ها هماهنگ شود.
- پاک‌کردن کش از صفحه مربوط به هر ابزار یا از تنظیمات مرورگر ممکن است.

## محدودیت‌ها و نکات فنی
- تولید chunkهای TTS پشت‌سرهم و در یک ورکر انجام می‌شود (نسخه Python از thread pool استفاده می‌کند)، بنابراین سنتز متن‌های طولانی کندتر است.
- نویز نمونه‌برداری TTS با PRNG داخلی تولید می‌شود؛ خروجی از نظر آماری معادل نسخه Python است ولی بیت‌به‌بیت یکسان نیست.
- جداسازی صدا روی دستگاه‌های بدون WebGPU با WASM اجرا می‌شود و برای فایل‌های طولانی زمان‌بر است.
- اجرای WebGPU و multi-thread WASM به مرورگر و دسترسی به `SharedArrayBuffer` (هدرهای COOP/COEP) بستگی دارد.
